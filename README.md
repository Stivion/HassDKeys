# Что это
Интеграция для управления ключами D-Keys из Home Assistant.

# Зачем
У меня около дома стоит шлагбаум такой фирмы, мне было бы удобно открывать его из Home Assistant.

# Что нужно для использования
Нужно авторизоваться в интеграции по номеру телефона, привязанному к учетной записи D-Keys. На указанный номер будет совершен звонок. Последние 6 цифр звонящего номера нужно будет ввести в форму в интеграции. После этого D-Keys выдают долгоживущий токен. С этим токеном и с номером телефона будут отправляться все запросы.

# Что поддерживается
Поддерживается только функционал ключей. Для каждого ключа в Home Assistant создается кнопка и если есть код доступа, то сенсор.
